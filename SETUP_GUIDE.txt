LOCAL DEVELOPMENT SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


STEP 1 — INSTALL REQUIRED SOFTWARE
─────────────────────────────────

Install these if you don't have them already:

  [ ] Python 3.11+          https://www.python.org/downloads/
      - During install: check "Add Python to PATH"

  [ ] Node.js 18+           https://nodejs.org/
      - Download the LTS version

  [ ] Git                   https://git-scm.com/downloads

  [ ] VS Code (recommended) https://code.visualstudio.com/

To verify everything is installed, open a terminal and run:
  python --version
  node --version
  npm --version
  git --version


STEP 2 — CLONE THE PROJECT
──────────────────────────

  git clone https://github.com/lama-Asiri/makeen-fintech.git
  cd makeen-fintech


STEP 3 — BACKEND SETUP (Python / FastAPI)
─────────────────────────────────────────

Open a terminal inside the backend/ folder:

  cd backend

  # Create a virtual environment
  python -m venv venv

  # Activate it
  Windows:   venv\Scripts\activate
  Mac/Linux: source venv/bin/activate

  # Install all dependencies (FastAPI, ML libraries, test tools)
  pip install -r requirements.txt

  NOTE: shap and scikit-learn contain compiled C extensions.
  Installation may take 1–3 minutes — this is normal.


--- BACKEND .env FILE ---

Create a file called  backend/.env  and fill in the values below.
Ask Lama for the actual keys — do NOT share them publicly.

  SUPABASE_URL=https://your-project.supabase.co
  SUPABASE_SERVICE_KEY=your-service-role-key
  OPENAI_API_KEY=your-openai-api-key
  FRONTEND_URL=https://makeen-topaz.vercel.app

  Where to find each value:
    SUPABASE_URL         → Supabase dashboard → Project Settings → API → Project URL
    SUPABASE_SERVICE_KEY → Supabase dashboard → Project Settings → API → service_role secret
    OPENAI_API_KEY       → platform.openai.com → API keys
    FRONTEND_URL         → use https://makeen-topaz.vercel.app (deployed frontend)


--- RUN THE BACKEND LOCALLY ---

  uvicorn app:app --reload

  Local backend will be running at: http://localhost:8000
  API docs available at:            http://localhost:8000/docs


STEP 4 — FRONTEND SETUP (React / Vite)
───────────────────────────────────────

Open a NEW terminal inside the frontend/ folder:

  cd frontend
  npm install


--- FRONTEND .env FILE ---

Create a file called  frontend/.env  and fill in the values below:

  VITE_SUPABASE_URL=https://your-project.supabase.co
  VITE_SUPABASE_ANON_KEY=your-anon-key
  VITE_API_URL=https://makeen-production.up.railway.app

  Where to find each value:
    VITE_SUPABASE_URL      → Supabase dashboard → Project Settings → API → Project URL
    VITE_SUPABASE_ANON_KEY → Supabase dashboard → Project Settings → API → anon public key
    VITE_API_URL           → https://makeen-production.up.railway.app (deployed backend)
                             or http://localhost:8000 if running backend locally

  IMPORTANT: Only variables prefixed with VITE_ are visible in the browser.
  Never put the service_role key or any secret in the frontend .env.


--- RUN THE FRONTEND LOCALLY ---

  npm run dev

  Local frontend will be running at: http://localhost:5173


STEP 5 — RUNNING THE FULL PROJECT LOCALLY
──────────────────────────────────────────

You need TWO terminals open at the same time:

  Terminal 1 (backend):
    cd backend
    venv\Scripts\activate      (Windows)
    uvicorn app:app --reload

  Terminal 2 (frontend):
    cd frontend
    npm run dev

Then open your browser at: http://localhost:5173

The project has 200 automated tests split across backend and frontend.
Tests run fully offline — no API keys or internet connection required.


--- BACKEND TESTS (137 tests) ---

  The backend tests use pytest. Because pytest is installed globally
  (not inside the venv), use python -m pytest instead of pytest directly.

  cd backend
  python -m pytest

  To see each test name:
    python -m pytest -v

  To run a specific file:
    python -m pytest tests/unit/test_data_processing.py -v
    python -m pytest tests/integration/test_auth_endpoints.py -v

  Expected result: 137 passed, 0 failed


--- FRONTEND TESTS (63 tests) ---

  cd frontend
  npm test

  To run in watch mode (re-runs on file save, useful while developing):
    npm run test:watch

  Expected result: 63 passed across 5 files, 0 failed

COMMON ERRORS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  "ModuleNotFoundError: No module named 'shap'"
  → Run: pip install shap scikit-learn lime

  "ModuleNotFoundError" for anything else
  → venv is not activated. Run: venv\Scripts\activate

  "pytest is not recognized"
  → Use python -m pytest instead

  "python is not recognized"
  → Python was not added to PATH during install. Reinstall and check the box.

  "npm is not recognized"
  → Node.js is not installed. Download from nodejs.org

  "Cannot find module 'vitest/config'"
  → Run: npm install   (inside the frontend/ folder)

  "CORS error" in browser
  → Backend is not running, or VITE_API_URL points to the wrong address.

  "Invalid API key"
  → backend/.env is missing or has wrong values. Check with Lama.

  SUPABASE_URL or SUPABASE_SERVICE_KEY is None
  → The key must be named SUPABASE_SERVICE_KEY (not SUPABASE_KEY).
