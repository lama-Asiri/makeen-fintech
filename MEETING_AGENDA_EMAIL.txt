          "prediction":  string    <- model output (e.g. "Approved")

          "lime_values": {}        <- { feature: value, ... } or null
        }

   B. LLM API Provider
      We need to pick one and get the API key ready.
      Options: OpenAI GPT-4o-mini / Claude / xAI Grok
      Recommendation: OpenAI GPT-4o-mini (cheapest, fastest, best documented)

   C. Target Column Selection
      How does the model know which column to predict on?
      Option 1: always use the last column in the dataset (fragile)
      Option 2: user selects from a dropdown after uploading the file (recommended)

   D. LIME Computation
      When should LIME be computed?
      Option 1: always alongside SHAP — adds ~20 seconds to every request
      Option 2: only when user clicks "Show LIME explanation" (recommended)
